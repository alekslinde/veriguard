# Trademarks

The code in this repository is open source. The **Veriguard** name, logo and
icons are not.

The licences in [`LICENSES/`](LICENSES/) cover the source code and written
content. None of them grants a right to use the Veriguard name, logo, icons or
store artwork (listed in [`REUSE.toml`](REUSE.toml) under
`LicenseRef-Veriguard-Brand`). Apache-2.0 says so explicitly in §6; the same
holds for the other licences here.

## What you can do

- Say that your project is based on, uses or is compatible with Veriguard.
- Link to the official site, repository, extension or npm packages by name.
- Show the logo unmodified when you're writing about the official project.

## What needs permission

- Publishing a fork, hosted service, browser extension or app under the
  Veriguard name or with its logo or icons. Forks are welcome; rebrand them.
- Using the name or logo in a way that suggests your project is official,
  endorsed, or affiliated.
- Modified versions of the logo or icons.

This matters more than usual for a scam checker. People act on its verdicts
while they're being targeted, so a copy that looks official but scores
differently, or collects what people paste, is exactly the kind of
impersonation the project exists to catch.

To ask for permission, open an issue on the
[repository](https://github.com/alekslinde/veriguard).
